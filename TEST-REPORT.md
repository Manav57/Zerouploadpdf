## What is covered

### `src/lib/core/formats.ts` — format registry
- `normalizeExtension` (case, missing extension, dotted files)
- `extensionToFormatKey` for every input type, scanned-PDF override, unknown types
- `mimeToFormatKey` for office/image MIME types
- extension uniqueness across native formats and OCR-kind flags

### `src/lib/core/tables.ts` — CSV + table reconstruction
- CSV quoting rules (commas, quotes) and newline normalization (no row injection)
- `rowsFromLines` / `rowsFromCells` / `rowsFromPairs`
- `groupTextItems`: line grouping by y proximity, column splitting by x gap,
  top-to-bottom ordering for both PDF (desc) and slide (asc) coordinates,
  merging of horizontally-adjacent fragments

### `src/lib/core/xlsx.ts` — workbook generation
- Unzippable package with the exact parts a spreadsheet app expects
  (`[Content_Types].xml`, `xl/workbook.xml`, rels, per-sheet worksheets)
- Correct cell references (A1/B1/C1), ordered multi-sheet output
- Sheet-name sanitizing and XML escaping of cell text

### `src/lib/core/ooxml.ts` — DOCX/PPTX extraction
- Parses a real generated `.docx` fixture and returns the expected table grid
- Parses a real generated `.pptx` fixture: slide tables + text fallback + slide count
- Throws on missing container parts; native-vs-scanned PDF byte classification

### `src/lib/core/pdf.ts` — PDF text extraction (pdfjs-dist)
- Covered via a mocked `pdfjs-dist` module (worker/browser path is exercised by
  the Phase 3 E2E suite and was verified manually in the browser):
  top-to-bottom row sheets, whitespace-only item pruning, page cap, confidence
  scoring for empty PDFs, `loadingTask.destroy()` cleanup

### `src/lib/core/pipeline.ts` — conversion pipeline
- OCR formats (png/jpg/pdf-scanned/doc/ppt) via injected transport
- OCR error code passthrough; OOXML native path; `no-text` detection for empty
  sheets and scanned PDFs; `bad-container` on broken archives; unsupported keys

### `src/lib/core/file-utils.ts`
- Byte-signature sniffing (docx/OLE/PDF/JPEG/PNG + unknown/short payloads)
- `formatBytes`, `extPart`/`baseName`, UTF-8 decode, standalone buffer copy

### `src/lib/limits.ts` — daily allowance
- `evaluate` boundary behavior; per-fingerprint/per-day incrementing
- Lockout at the daily limit; independence of fingerprints; UTC-day reset
- `utcDateKey`, `nextUtcMidnight`, hex nonces

### `src/lib/shares/demo.ts` + `src/server/ocr-provider.ts`
- Deterministic demo invoice generation, OCR-shaped result, empty-upload rejection

## Not covered by unit tests

- `fileToString` (browser `FileReader` only)
- `nonceHex` fallback branch behind `crypto.getRandomValues`
- Real pdfjs worker/rendering — covered by the Phase 3 Playwright suite against
  generated fixtures in `tests/fixtures/`
